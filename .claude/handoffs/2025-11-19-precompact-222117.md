## Architectural Context

### Key Decisions

1. **Performance Hierarchy**: Rust > Go > Native Binaries > Node.js/TypeScript
   - Rationale: Rust/Go provide 3-100x faster performance with minimal memory footprint
   - Impact: Better Claude Code experience, especially for large codebases

2. **ty as Default Python LSP**
   - Rationale: Astral team (makers of uv, ruff) focus on performance, 26x faster than pyright
   - Alternative: Both python/ and ty/ directories exist for user choice

3. **No VSCode Dependencies**
   - Rationale: Avoid bloated dependencies, ensure LSPs work independently
   - Replaced: vscode-langservers → superhtml + emmet-language-server

4. **vtsls for React/SolidJS**
   - Rationale: No separate LSPs needed, vtsls handles all JSX/TSX frameworks natively
   - Benefit: Single LSP for TypeScript, React, SolidJS, Preact, Qwik

### Patterns Used

- **Dual LSP Options**: Provide both `python` (default) and `ty` for same LSP (user flexibility)
- **Marketplace as Catalog**: `.claude-plugin/marketplace.json` lists all plugins with `source` paths
- **Plugin Structure**: Every plugin has `plugin.json` (metadata) + `.lsp.json` (LSP config)
- **Batch Email Updates**: Used sed for atomic replacement across all 25+ files
- **Sparse Git Checkout**: Installed plugin-dev toolkit without cloning entire anthropics/claude-code repo
